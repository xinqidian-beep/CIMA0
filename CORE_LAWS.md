# CIMA0 Core Laws


## 1. Planet

archive/planet.py is the seed.

It is:

- self-existing
- self-evolving
- independent

Rules:

- no modification
- no optimization
- no replacement
- no duplication

Allowed:

- run
- snapshot
- observe


Planet answers:

"How does the internal field move now?"

## 2. CloudField

CloudField is an internal persistent structure.

It is:

- a local subset of Planet space
- slow variable structure
- continuously co-evolving with Planet


Rules:

- not a copy of Planet
- not a snapshot cache
- not an external feature map


CloudField answers:

"Which structures persist inside the evolving field?"

## 3. Observer

Observer receives local projections.

It is:

- readonly
- local
- interpretive


Rules:

- no modification of internal dynamics
- no access to complete internal state


Observer answers:

"What can be interpreted from this local observation?"

## 4. External Disturbance

External input is disturbance, not control.

Rules:

- no overwrite of Planet state
- no replacement of internal dynamics


External input may:

- perturb
- influence tendency
- change future evolution
