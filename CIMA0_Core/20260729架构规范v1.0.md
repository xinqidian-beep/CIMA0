CIMA0 Core 架构规范 v1.0
一、总原则
1. 局部自治原则

每个模块：

只管理自己的状态。
不理解全局。
不拥有其他模块。
不直接控制其他模块。

统一形式：

自身状态

↓

自身规则

↓

自身演化

↓

输出局部投影
二、四模块职责
1. KinEngine（动力核心）

文件：

core/planet.py

职责：

最小动力系统。

自身状态：

x
v
omega

允许：

step
drift

禁止：

memory
reward
goal
controller

它不知道：

Cloud
Observer
Compute
IO
2. CloudField（三值媒介）

文件：

core/cloud.py

职责：

三值状态演化。

三值：

void

neg

act

输入：

只有两类扰动：

IO扰动

Observer采样扰动

Cloud不解释：

图片
声音
文字
意义
3. IOField（边界）

文件：

core/input_field.py

职责：

只有：

输入：

bytes

输出：

bytes

禁止：

feature
embedding
classification
semantic

IO不是大脑。

4. Observer（观察）

文件：

core/observer.py

职责：

多尺度稀疏扫描：

粗扫描

↓

发现偏离

↓

缩小区域

↓

精采样

↓

举手

Observer不拥有：

全局状态
完整历史
完整地图
