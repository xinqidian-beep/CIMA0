CIMA0 模块审查标准（固定）

每个 .py 文件逐一检查：

检查一：命名规则

机械检查：

域归属

模块内部名称必须属于自己的域。

例如：

模块	允许前缀
IO	io_ / gate_
Cloud	cloud_ / sieve_
动力	kin_ / field_
观察投影	sample_ / proj_
计算资源	compute_
生命周期

瞬时量：

必须：

_ephemeral_
_temp

禁止：

history
memory
archive
cache
行为

允许：

step_
drift_
sample_
evaluate_
project_

避免：

control_
manage_
override_
检查二：自治边界

每个模块必须回答：

1. 它只知道什么？
2. 它不知道什么？
3. 它是否修改其他模块？
4. 它是否试图理解全局？
